# HireMindAI (Frontend Client) 🤖💼

> **Tech Expo 2026 Winner (Parul University)** – An AI-powered mock interview and career preparation platform designed to help candidates land their next engineering role.

HireMindAI automates the interview lifecycle by offering role-based mock interviews, real-time behavioral tracking, dynamic AI chat, personalized learning roadmaps, and instant resume analysis.

## 🚀 Key Features

* **🎭 Role-Based Mock Interviews:** Simulates technical and behavioral interviews tailored to specific job descriptions or tech stacks using advanced LLMs.
* **👁️ Real-Time Face Monitoring:** Integrates MediaPipe Facemesh to track candidate engagement, focus, and eye contact during simulated sessions.
* **🗣️ Voice Synthesis:** Uses ElevenLabs API for realistic audio-based questions and conversational streaming.
* **📈 AI Roadmap Generation:** Dynamically builds comprehensive learning paths based on identified skill gaps post-interview.
* **📄 Automated Resume Analysis:** Parses uploaded resumes to evaluate alignment with target roles, highlighting missing keywords and giving optimization tips.

---

## 🛠️ Tech Stack
### Frontend
* **Framework:** Next.js (React) with TypeScript
* **Styling:** Tailwind CSS + Radix UI Components
* **State Management:** React Hooks & Context API
* **Authentication:** NextAuth.js (Integrated with Strapi Backend)
* **AI & Media Interactivity:** OpenRouter (GPT-4o-mini), ElevenLabs (Voice Synthesis), MediaPipe Face Mesh (Face Tracking)

### Backend Services
* **Core Engine & CMS:** Strapi CMS (Node.js)
* **Database:** PostgreSQL  
* **ORM/Query Builder:** Strapi ORM (built-in)
